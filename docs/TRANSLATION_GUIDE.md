# 번역 지침

- 기계 번역을 쓰지 않고 모두 직접 번역합니다.
- 군사 용어는 국내에서 흔히 쓰는 표기를 따릅니다(주력전차, 자주포, 지대공 미사일, 수송 헬기 등). 유닛 고유 이름은 원어 발음 또는 국내 통용 표기(90식 전차, 천마호 등)를 씁니다.
- 가상 국가 이름은 원문의 머리글자 체계를 살립니다(J국, K민국, N인민국, A합중국, R공화국 등).
- 줄 폭은 원문 한 줄의 폭(전각 2, 반각 1 단위)을 넘지 않게 합니다. 번역문 앞에 `#` 를 붙이면 빌드 때 원문 줄 구성에 맞춰 자동 줄바꿈합니다.
- `{1FF}` 같은 중괄호 코드는 제어 코드이므로 그대로 둡니다.
- 시나리오 이름은 세이브 데이터 설명 칸(UTF-8 바이트 수 제한)에 들어가야 하므로 짧게 줄인 곳이 있습니다.
- 그림 글자는 원본 글자가 있던 영역 안에만 그립니다. 넘치면 한 단계 작은 글꼴로 바꿉니다.
